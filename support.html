Using NotchMate

NotchMate requires an Apple Silicon Mac running macOS 13.0 or later.

Get started

  1. Install and launch NotchMate from the Mac App Store.
  2. Choose the notch or menu bar display mode.
  3. Open Settings and select AUTHORIZE CODEX FOLDER.
  4. Use the macOS system picker to select your local .codex folder.
  5. Save and restart NotchMate, then open the panel to view status, quota, session, and usage information.

Frequently asked questions

Why does NotchMate show SETUP or ask for authorization?

The App Store build runs in the App Sandbox. NotchMate can read your .codex data only after you authorize that folder through the macOS system picker. Access is read-only.

Why are some values missing?

NotchMate does not invent values a provider does not supply. A field may be hidden or marked unavailable when a provider is not installed, offline, incompatible, stale, or temporarily unavailable.

Why is network latency unavailable?

Network connectivity, system proxies, firewalls, or service-side limits can prevent the credential-free OpenAI path probe from completing.

Why is SmartWork status unavailable?

The SmartWork integration depends on a supported service running locally at 127.0.0.1. NotchMate does not generate substitute data when that local interface is unavailable.

How do I disable launch at login?

Turn off LAUNCH AT LOGIN in NotchMate Settings. You can also manage login items in macOS System Settings.
